# 평가 리포트

조건 간 비교표와 그래프 산출물을 둔다. 입력은 run 디렉터리의 `trace.jsonl`과
`run_manifest.json`이며, 기록이 불완전한 run은 비교표에 넣지 않는다(evaluation.md §6).

## 적용 사례

`repo_dirty` 필드가 없는 `run_manifest.json`은 그 필드가 도입되기 전의 산출물이다.
그 run이 하네스 저장소의 미커밋 변경 위에서 돌았는지 알 수 없으므로 재현성 기록이
불완전하고, 따라서 위 규칙대로 **비교표에서 제외한다.** 다시 돌려 새 기록을 남긴다.

값이 `null`인 경우도 같다 — `null`은 "확인 못 함"이지 "깨끗함"이 아니다.
