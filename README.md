# whitehat-boss
소형 LLM 앙상블 기반 취약점 연구 Multi-Agent Orchestration | 화이트햇스쿨 4기 2차 프로젝트 — 화햇대장

이 저장소는 **하네스 개발 전용**이다([ADR 0012(제안)](docs/decisions/0012-harness-canon-v2.md) 결정 5) — 하네스가
파일로 받는 입력을 만드는 도구(루트의 `slicer*.py`)도 여기서 개발한다. 실험 기록의 원천은 팀 Notion 워크스페이스
[화햇대장](https://app.notion.com/p/3aebec1a15bc80c18c66fddd77844013)이고, `docs/experiments/`·`docs/research/`는
옮기지 않고 보관한다. 하네스 결정의 근거가 된 실험은 ADR·D 본문에 요약과 링크로 남긴다.
