# whitehat-boss
소형 LLM 앙상블 기반 취약점 연구 Multi-Agent Orchestration | 화이트햇스쿨 4기 2차 프로젝트 — 화햇대장

이 저장소는 **하네스 개발 전용**이다([ADR 0012](docs/decisions/0012-harness-canon-v2.md) 결정 5) — 하네스가
파일로 받는 입력을 만드는 도구(루트의 `slicer*.py`)도 여기서 개발한다. **하네스를 돌린 run 기록**(스모크·서빙
실측)은 `docs/experiments/`에, **하네스 결정·결함의 근거가 되는 조사**는 `docs/research/`에 남긴다. 실험팀
실험(모델 비교·선정, 조건·벤치마크 설계, 데이터셋, 프롬프트 A/B)의 원천은 팀 Notion 워크스페이스
[화햇대장](https://app.notion.com/p/3aebec1a15bc80c18c66fddd77844013)이고, 하네스 결정의 근거가 되면 ADR·D 본문에
요약과 링크로 남긴다.
