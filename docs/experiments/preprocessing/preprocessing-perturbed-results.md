계산 방법은 다음과 같다.
- 정확도(Accuracy)  = (TP + TN) / (TP + FP + FN + TN)     ← 전체에서 맞힌 비율
- 정밀도(Precision) = TP / (TP + FP)                      ← "취약" 판정 중 진짜 비율
- 재현율(Recall)    = TP / (TP + FN)                      ← 실제 취약점 중 잡아낸 비율
- F1 = 2 × 정밀도 × 재현율 / (정밀도 + 재현율)

모든 수치는 소수점 다섯째 자리에서 반올림하여 소수점 넷째 자리까지 표시하였다.
