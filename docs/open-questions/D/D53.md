## 내용

**해소 · (a) 채택.** `ModelGatewayError`·`SchemaParseError`가 이미 쓴 `usage`·`gpu_ms`·`attempts`를 실어 올리고, `context.call_model`의 실패 경로가 예외가 소비를 들고 왔을 때 장부에 청구한다. 실패 `model_call` 이벤트도 토큰·gpu 키를 성공 경로와 **균질하게** 싣는다(소비를 들고 왔으면 값, 아니면 `None`). **게이트웨이 거절도 자기 시도의 wall-clock을 `gpu_ms`에 실어**(재보지 않은 0에 실측 라벨을 붙이지 않는다) 타임아웃으로 죽은 폭주까지 장부에 든다. `Budget.charge`의 "이미 일어난 소비를 기록한다"는 정의와 맞고, #83과 한 PR이다.

**두 가지 주의.** (1) 실패분 청구가 `budget` 이벤트를 하나씩 늘려, D53을 탐지한 항등식(`budget` 수 = ok `model_call` + `tool_call`)이 더는 성립하지 않는다 — 새 항등식은 (소비를 든) `model_call` + `tool_call` + `retrieval_call`이고, **과거 run과 이 수로 대조하지 않는다.** (2) 실패분 청구가 상한을 넘기면 **run이 조기 종료될 수 있다**(다음 단계 `ensure()`가 막는다) — 실패 한 건이 종료 시점을 바꾼다.

아래는 등재 당시 진단이다.

**2026-08-29 실측**([v2 스모크 보고서](../../experiments/harness/2026-08-29-prompt-v2-smoke-atom.md) §7.1). `context.call_model`의 실패 경로(174~190행)가 `model_call` 이벤트만 내고 **`self.ledger.charge`(220행)를 부르지 않는다** — 그 줄은 성공 경로에만 있다. **이벤트 수가 그것을 직접 보인다**: `budget`이 run B **38 = ok `model_call` 25 + `tool_call` 13**이고 v2 **41 = ok 28 + 13**이다. v2의 `model_call`은 31인데 장부는 **28만 셌다**. **무엇이 틀리나**: [evaluation.md](../../evaluation.md) §5.2의 `input/output token` · `GPU-second` · "validated finding당 GPU-hour" · "백만 input token당 유효 finding"의 **분자가 빈다.** v2에서 장부 밖으로 나간 것이 **wall-clock 729초**(`critic_failed` 3건 × 243초, run의 60.7%)와 출력 토큰 최대 6 × 8,192다. **243초의 출처는 `model_call.wall_ms`다** — 장부가 받았을 값은 `result.gpu_ms`이고 `gpu_ms_source == "request_wall_clock"`이라 가깝지만, `wall_ms`가 `_record_prompt` **뒤**부터 재므로(`context.py` 170~171행) 조금 크다. `evaluation.md` §5.2가 "GPU-second는 출처 라벨과 함께 읽는다"고 정한 자리라 둘을 안 뭉갠다. **이것은 `openai_compat.complete()`가 어댑터 안에서 없앤 바로 그 편향이 한 겹 위에서 되살아난 것이다** — 그 주석(74~87행)이 "마지막 시도만 세면 재시도가 잦은 모델일수록 비용이 싸 보인다. 조건 간 비교에서 정확히 거꾸로 가는 편향이다"라고 적었는데, **호출이 통째로 실패하면 0으로 센다.** 선택지: **(a)** `ModelGatewayError`·`SchemaParseError`가 `usage`·`gpu_ms`를 실어 올리고 실패 경로가 청구한다 — `src/interfaces/model_client.py`에 필드가 늘지만 "이미 일어난 소비를 기록한다"는 `Budget.charge` docstring의 정의와 맞는다 **(b)** `complete()`가 예외 전에 부분 `ModelResult`를 남긴다 — 반환 타입이 흔들린다 **(c)** 그대로 두고 "실패분은 장부 밖"을 문서로 명시한다 — 비용표를 읽는 사람이 매번 trace를 따로 세야 한다. **⚠ ~~팀 2×2가 도는 중에는 고치지 않는다~~ → **2026-09-01 2×2 전량 폐기로 이 대기 단서는 소멸했다. 아래는 그때의 사유다.** — 비용표의 분자가 걸린 값이라 셀마다 다른 코드로 돌면 비교가 깨진다. 큐는 2×2 전량 완료 직후다
