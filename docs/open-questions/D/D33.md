## 내용

**해소 — 재측정 완료.** `run_20260826_0001`(재측정 보고서)이 새 기준선이 되고, 옛 `run_20260825_0001`은 지우지 않고 '옛 배선'으로 표시한다. 2026-08-25 배선 수정(`-I` 추가 + 방언 분리)으로 `clang-tidy`가 살아나면 **`signal_artifacts`(현재 19)가 늘어난다.** 그러면 `_order_and_cut()`의 (a′) 정렬 키 첫 항이 `not item.signal`이므로 **후보 순서가 바뀌고**, 후보 순서가 곧 ID 발급 순서이자 scout 입력이라 **두 run의 trace를 대조할 수 없다.** [evaluation.md](../evaluation.md) §2.3 규칙 2("조건 간 차이는 프로필과 파이프라인 단계 활성화만")에 걸린다 — 도구 배선은 그 예외 목록에 없다. **즉 이 수정 전후의 run은 같은 비교 셀에 넣을 수 없다.** 기대 효과(C 소스 48 중 약 46 성공)는 **추정이고 확정은 재측정 run 1회**다 **선택지**: (a) 재측정 run을 돌려 새 기준선을 만든다 — 필요하다 (b) 옛 run을 비교에서 제외한다 — `run_20260825_0001`은 [542건 보고서](../experiments/harness/2026-08-25-pipeline-zlib542-atom.md)의 근거이므로 **지우지 않고 "옛 배선"으로 표시**한다
