## 왜 위험한가

recall 천장. 여러 곳에서 불리는 메모리 쓰기 함수가 곧 흔한 취약 지점인데 Case A에서 체계적으로 빠짐. [D91](D91.md)의 「앵커 패턴 공백」으로 보였던 다섯도 실제 원인은 이쪽.
