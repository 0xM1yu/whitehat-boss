# D12 — build를 몇 단계에서 실행하는가

| 상태 | 관련 문서 |
| --- | --- |
| 열림 | [architecture.md](../architecture.md) §3 |

> 인덱스: [docs/open-questions.md](../open-questions.md) · 작업 추적은 GitHub Issue

## 내용

[architecture.md](../architecture.md) §3은 build를 8단계(Tool Validation) 소관으로 두고 2단계는 sanitizer 로그를 "파싱"하는 단계로 정의한다. 그런데 Auditor는 빌드 가능 여부를 모르면 `repro_spec`을 쓰지 않고, 그러면 E3이 성립하지 않아 **8단계가 영원히 도달 불가**가 된다(도구 검증 제거율의 분모가 0). 현재 코드는 2단계에 build 프로브를 넣어 해결했다. 선택지: (a) §3을 코드에 맞춰 2단계에 build를 포함하도록 고친다 (b) `repro_spec` 생성 조건에서 BUILD 요구를 빼고 8단계가 빌드 실패를 직접 처리한다
